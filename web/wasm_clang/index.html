Controls

The panel is collapsed by default so it does not cover the game. Keyboard, Gamepad API controllers, and touch buttons are remappable here. Default keyboard controls: Arrow keys or WASD to move, Z or Enter to confirm, X or Space to cancel/jump, P or Escape to pause, C/V for B, Q/E for L/R, Tab for Select.
